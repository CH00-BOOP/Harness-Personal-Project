## 阅读建议

- 想先建立全局认知：读根目录的 `docs/项目架构解读-AI-Agent.md`。
- 想搞懂「AI 是怎么越用越聪明的」：直接读本系列 **01**。
- 想搞懂「教过的东西在客户提问时怎么被找回来用上（RAG）」：读本系列 **02**（建议先读 01 再读 02）。
- 想搞懂「每轮到底喂给 AI 一份什么样的工作守则（系统提示词）」：读本系列 **03**。
- 想搞懂「一次对话内部引擎怎么一步步调度、什么时候停」：读本系列 **04**。
- 想动手搭一套「CC 式」上下文管理子系统（模块/数据模型/装配流程）：读本系列 **05**（配合根目录的对标 Claude Code 理念篇一起看）。
- 想搞懂「训练素材越来越多，怎么不把套路总纲撑爆」：读本系列 **06**（分域 + 按需注入 + 冷热淘汰，配合 05 的「预算而非容器」心智）。
- 想搞懂「loop 每轮都调 LLM 会不会拖慢客服回复、怎么优化」：读本系列 **07**（延迟构成 + 流式 + recall 预取等六招，建议先读 04 再读 07）。
- 想搞懂「怎么把线上真实对话拿来自动学习、走向真·自进化」：读本系列 **08**（结果信号驱动 + 人审闸门的挖掘闭环，建议先读 01 再读 08）。
- 想搞懂「传统意图路由 / LLM 意图路由 / Agent Loop 三者到底差在哪」：读本系列 **09**（同 case 贯穿三代，核心看「谁决定控制流」，建议配合 04 一起看）。
- 想搞懂「爆火的 Graph Engineering 是什么、和 Agent Loop 什么关系」：读本系列 **10**（术语新技术旧、能力阶梯、loop 被降级为图节点，建议先读 04 再读 10）。
