# AI 课程咨询 Agent 系统 —— 架构设计与核心研发

> 从零设计并实现一套**模型无关、工具可插拔的 Agent 运行时底座(Harness)**,支撑可自主决策、可自我进化的智能客服 Agent。架构范式对齐 Claude Code,核心解决"如何用一个通用循环 + 标准化工具承载复杂多变的业务,而非堆砌流程编排"。
>
> **角色**:架构设计 + 核心研发　|　**技术栈**:Python · FastAPI · OpenAI SDK(火山引擎 ARK / 豆包 function calling)· SQLite · 向量语义检索

---

### 一、Harness 架构底座:模型无关、工具可插拔的 Agent 运行时

- **双抽象 + 注册表解耦**:以 `LLMProvider` 抽象隔离大模型、`Tool` 抽象 + 注册表承载能力,Loop 引擎**只依赖接口、与具体模型/工具零耦合**;新增模型仅实现一个 `chat()` 适配器,新增能力仅登记一个 `Tool`,业务与循环代码零改动。
- **模型热切换**:配置驱动在「离线 Mock 桩」与「真实大模型」间一键切换——Mock 保证 CI/演示可离线复现,ARK 接入真实豆包,同一套 Loop 无差别运行。
- **标准化消息协议**:内部统一采用 `tool_call / tool_result` 配对结构,与 OpenAI / Anthropic function calling 同构,**provider 层近乎零转换成本**,可平滑接入任意兼容模型;相比早期自定义格式需在适配层伪造调用配对,重构后彻底消除该耦合。

### 二、Agent Loop 架构:模型自主决策的推理-行动循环

- **Model-driven 自主循环**:实现"推理 → 工具选择 → 调用 → 观察 → 再决策 → 终止"闭环,**决策权完全交给模型**,意图识别隐式融入工具选择,**去除独立意图分类模块**——这正是 Claude Code 式 Agent 与传统 Workflow 的架构分水岭。
- **单步多工具并行**:重构 `LLMDecision` 支持一步并行发起多个工具调用并批量回填观察结果,提升复杂问题处理效率(对齐主流模型的 parallel tool use)。
- **"错误即上下文"自纠错**:工具异常 / 未知调用被捕获并转为 observation 回填,由模型自我纠正而非中断会话,显著提升鲁棒性。
- **确定性边界护栏**:内置最大步数 + 超时双重限制防止死循环与失控,超限自动降级转人工,保证服务可预期。
- **全链路可观测**:结构化记录每一步"思考-调用-结果"Trace,前端可视化 Agent 决策链路,支撑演示与线上排障。

### 三、AI 自进化:示范学习 + 人在环自纠错闭环

- **示范学习替代微调**:业务专家以「问题 + 标准答案 + 套路原因」对话式教学 → 样本入库 → LLM 自动归纳"套路总纲" → 注入系统提示词驱动真实回复。相比微调,**轻量、可解释、改完即时生效**,更契合业务话术高频迭代。
- **语义泛化,举一反三**:服务时以向量语义检索召回最相关样本(top-k)交大模型精判,**换问法 / 相似意图自动命中套路**,未教过且无把握的问题自动转人工,守住事实红线。
- **状态合并(可控进化)**:套路总纲支持人工改写并持久化,重归纳时**以人工版为基底增量融合新样本**(冲突以人工为准),坚持单一数据源、杜绝规则漂移。
- **自纠错闭环 + 点评式教学**:答不上 → 工单 → 专家补充 → 入库 → 下次答对;并支持实测中对回复提"纠偏意见",Agent 即时重答、满意后一键固化为样本并自动合并进总纲。
- **提示词分层治理**:业务铁律 > 套路总纲 > 召回样本话术,分层拼装、优先级明确,保障报价等高风险动作可控。

### 四、上下文工程:有限预算下的信息架构(对标 Claude Code)

- **以"预算账户"而非"容器"建模上下文**:核心目标是**最大化信噪比**而非塞满窗口,规避 context rot(窗口未满但噪声稀释注意力、模型反而退化)。
- **架构已内含三重上下文管理**(非事后补丁):① 会话仅持久化「用户消息 + 最终回复」、**剥离工具调用与原始返回**(等价 Claude Code 的 T1 微压缩);② **套路总纲 = 对全量样本的语义级压缩**,以精炼原则替代原始样本入提示词;③ recall_playbook 采用 **火山引擎 embedding 向量 top-k 语义检索**(问句语义匹配、只召回最相关 N 条),即"按需检索"取代"全量塞入"。
- **分层压缩演进设计(越贵越晚用)**:规划 T1 删(免费)→ T2 归档搬家(免费)→ T3 折叠(调模型,将多轮零散信息摘要为一句"客户画像")→ T4 全量(调模型,砸成结构化"会话档案",含原始诉求逐字保留),遵循"能用便宜手段绝不用贵的"。
- **外部存储双写兜底**:关键事实(客户画像、意向强度、是否已引导对接班主任)主动落盘至窗口外持久层,压缩不可及、压缩后读回补漏——**正因有此保险,压缩才敢压得狠**;项目已具备样本库/总纲/指标等外部记忆雏形。
- **常驻税治理**:系统提示词按"业务铁律(规则)+ 召回样本(示例)"分离,规则紧凑覆盖、示例按需供给;规划套路总纲**分域**(价格/学历/就业等)+ 动态上下文组装,只注入与当前问题相关分域,抑制常驻成本随教学线性膨胀。
- **克制的工程判断**:识别子 Agent「脏活隔离」适用边界(某步会拉回海量原始内容时),但基于当前对话短、库小的规模**明确判定为过度设计而暂不引入**,仅预留扩展口——知道何时"不做"同样是架构能力。
