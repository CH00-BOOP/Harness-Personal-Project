# AI 课程咨询 Agent 系统 —— 架构设计与核心研发

> 从零设计并实现**模型无关、工具可插拔的 Agent 运行时底座(Harness)**,支撑可自主决策、自我进化的智能客服 Agent,架构范式对齐 Claude Code。
>
> **角色**:架构设计 + 核心研发　|　**技术栈**:Python · FastAPI · 火山引擎 ARK/豆包(function calling)· 向量语义检索 · SQLite

---

- **Harness 底座(模型无关/工具可插拔)**:以 `LLMProvider` + `Tool` 双抽象 + 注册表解耦,Loop 引擎只依赖接口;新增模型仅写一个 `chat()` 适配器、新增能力仅登记一个 `Tool`,循环与业务代码零改动;配置驱动在离线 Mock 与真实豆包间热切换,内部 `tool_call/tool_result` 协议与主流 function calling 同构、近乎零转换成本。

- **Agent Loop(模型自主决策)**:实现"推理→选工具→调用→观察→再决策→终止"闭环,**决策权完全交给模型、意图识别隐式融入工具选择**(去除独立意图分类模块);支持单步多工具并行;工具异常转 observation 回填由模型**自纠错**而非中断;最大步数+超时双重护栏,超限自动转人工;全链路 Trace 可视化。

- **AI 自进化(示范学习替代微调)**:业务专家以「问题+答案+套路原因」对话式教学 → 样本入库 → LLM 自动归纳"套路总纲"注入提示词,**改完即时生效**;服务时向量 top-k 召回样本语义精判,换问法/相似意图自动命中,没把握则转人工;支持"答不上→工单→补充→下次答对"与点评式纠偏一键固化;提示词分层治理(业务铁律 > 总纲 > 召回话术)保障报价等高风险动作可控。

- **上下文工程(对标 Claude Code)**:以"预算账户"而非"容器"建模,追求信噪比、规避 context rot;架构**已内含三重管理**——会话剥离工具噪声(T1 式)、总纲对样本的语义压缩、recall 的 top-k 按需检索;规划分层压缩(T1 删/T2 搬/T3 折叠客户画像/T4 结构化会话档案,越贵越晚用)+ 关键事实外部存储双写兜底;并能界定子 Agent 适用边界、按当前规模判定暂不引入以避免过度设计。

---

**架构判断力**:清晰界定 Workflow 与 Agent 的边界;明确原型→生产的演进路径——分层压缩 + 客户画像折叠、单一总纲 → 分域动态组装、纯模型判断 → 高风险动作确定性闸门 + 评测回归、进程内会话 → 分布式会话与可观测体系。
