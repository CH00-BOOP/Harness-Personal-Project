# Seedance 视频生成全流程演示 —— 「主播介绍养老产品」案例

> 面试演示用文档。目标：用一个完整、可复述的案例，讲清楚 Seedance（字节跳动视频生成模型，火山引擎方舟 / 即梦同源）从**提示词 → 分镜 → 生成 → 结果 → 迭代优化**的端到端链路，并说明它如何嵌入到我们的电商 AI 生态（多模态素材中心 + 内容运营 Agent + 直播切片）里落地。

---

## 一、先给面试官一句话结论

> 「Seedance 的本质是**把结构化的镜头语言翻译成时序像素**。所以真正的工程活不在于'点生成按钮'，而在于**提示词工程 + 分镜编排 + 首帧控制 + 结果评测回流**这一整套流水线。我用一个『虚拟主播介绍养老产品』的场景，把这条链路完整走一遍。」

---

## 二、Seedance 能力速览（面试背景铺垫）

| 维度 | 说明 |
|------|------|
| 生成模式 | 文生视频（Text-to-Video）/ 图生视频（Image-to-Video，用首帧图控人物一致性）|
| 时长 | 单次 5s / 10s，长视频靠**多镜头拼接**（首尾帧衔接）|
| 分辨率 | 480p / 720p / 1080p |
| 强项 | 多镜头叙事、镜头运动控制（推拉摇移）、高提示词遵循度、主体一致性 |
| 关键控制项 | 首帧图、镜头运动、运镜速度、时长、seed（复现）、负向约束 |

**面试要点**：文生视频适合从 0 生成创意；但做**电商带货主播**这种要求「人物长相稳定、口播对齐」的场景，主路线是**图生视频 + 首帧锁人 + 分镜拼接**，最后再叠加数字人口型 / TTS 配音。

---

## 三、场景设定：养老产品带货短视频

- **产品**：一款适老化「智能防摔手环」（跌倒自动报警 + 一键呼叫子女 + 心率监测）。
- **目标人群**：给父母买产品的中年子女 + 银发人群本身。
- **成片诉求**：15 秒竖屏短视频，一位亲和、可信赖的中年女主播在温馨居家场景介绍产品，节奏「痛点 → 产品 → 卖点 → 行动号召」。
- **平台**：抖音竖屏 9:16。

---

## 四、完整流程（这是演示的核心）

整体链路分 6 步，我会**每一步都给出实际产物**：

```
需求拆解 → 分镜脚本 → 首帧图(锁人锁场景) → 逐镜头提示词 → 生成&拼接 → 评测&迭代回流
```

### 步骤 1：需求拆解（把「带货」翻译成镜头）

把 15s 拆成 3 个镜头，对应营销结构：

| 镜头 | 时长 | 叙事作用 | 画面 |
|------|------|----------|------|
| 分镜① | 5s | 痛点共鸣 | 主播特写，关切表情，居家客厅背景 |
| 分镜② | 5s | 产品展示 | 主播手持手环，镜头推近到手腕，展示屏幕 |
| 分镜③ | 5s | 卖点+号召 | 主播中景，微笑点头，背景虚化，字幕位留白 |

### 步骤 2：结构化提示词模板（我的方法论）

我用固定六段式结构写 Seedance 提示词，保证可复用、可对比、可回流评测：

```
【主体】谁 + 长相/年龄/穿着/表情
【场景】在哪 + 环境细节 + 道具
【动作】主体在做什么（要具体、可被时序化）
【镜头】景别 + 运镜方式 + 速度（推/拉/摇/移/固定）
【风格】画质/色调/光影/氛围
【负向】不要出现什么（多手指、变形、文字乱码等）
```

> 面试话术：**「主体和场景决定一致性，动作和镜头决定时序质量，风格决定调性，负向约束决定良品率。」**

### 步骤 3：首帧图 —— 锁定人物与场景（一致性关键）

带货主播必须「三个镜头是同一个人、同一间屋」。做法：

1. 先用文生图（即梦 / Seedream）生成一张**主播首帧图**，固定 seed。
2. 该图作为分镜①的首帧，分镜①的**尾帧**作为分镜②首帧，依次衔接 → 保证人物与光影连续。

**首帧图提示词示例**：

```
一位约 50 岁、温柔亲和的中国女性主播，短发、米色针织衫，面带真诚微笑；
坐在温馨明亮的居家客厅，背景有绿植和暖色沙发，浅景深；
柔和自然光，暖色调，真实电商直播质感，竖屏 9:16，高清写实。
负向：多余手指、面部扭曲、文字水印、塑料感。
```

### 步骤 4：逐镜头「图生视频」提示词（完整产出）

**▶ 分镜① —— 痛点共鸣（5s）**

```
【主体】50 岁亲和女主播，米色针织衫，眉头微蹙、眼神关切，像在跟屏幕前的子女说话
【场景】温馨居家客厅，暖色沙发与绿植，浅景深
【动作】主播缓缓向前微倾身体，轻轻点头，嘴唇自然开合像在讲述
【镜头】胸部以上特写，镜头极缓慢推近（slow push-in），运镜平稳
【风格】暖色调，柔和自然光，真实直播质感，写实，竖屏 9:16
【负向】多手指、面部扭曲、快速抖动、文字水印、卡通感
```

**▶ 分镜② —— 产品展示（5s，衔接分镜①尾帧）**

```
【主体】同一位女主播，手腕佩戴银色智能防摔手环，手环屏幕亮起显示心率数字
【场景】同一客厅，主播抬起手腕靠近镜头
【动作】主播抬手展示手环，另一只手手指轻点手环屏幕，屏幕微微发光
【镜头】从中景缓慢推近到手腕特写（push-in to wrist close-up），聚焦手环
【风格】暖色调，产品高光质感，清晰锐利，写实，竖屏 9:16
【负向】手环变形、屏幕文字乱码、多余手指、画面抖动
```

**▶ 分镜③ —— 卖点+行动号召（5s，衔接分镜②尾帧）**

```
【主体】同一位女主播，自信温暖微笑，眼神看向镜头
【场景】同一客厅，背景进一步虚化，画面右侧留白（给字幕/贴片）
【动作】主播微笑点头，双手自然摊开做出「推荐」姿态
【镜头】中景固定机位（static），轻微呼吸感运镜
【风格】暖色调，明亮温馨，可信赖氛围，写实，竖屏 9:16
【负向】表情僵硬、跳帧、多手指、背景人物乱入
```

### 步骤 5：生成参数与拼接

| 参数 | 取值 | 理由 |
|------|------|------|
| 时长 | 每镜头 5s | 竖屏短视频节奏 |
| 分辨率 | 1080p | 电商投流画质门槛 |
| 帧率 | 24/30 fps | 口播自然度 |
| seed | 固定 | 便于复现与 A/B 对比 |
| 衔接 | 首尾帧接力 | 保证人物/光影连续 |

**后处理链路**：3 段视频 → 剪辑拼接 → 叠加 TTS 口播（声音复刻，情绪化）→ 对齐口型（数字人/对口型模型）→ 加字幕/贴片 → 导出竖屏成片。

### 步骤 6：结果预期 + 评测与迭代（体现工程思维）

**结果**：一条 15s 竖屏视频，同一位可信主播在温馨居家场景，从「关切痛点」自然过渡到「手腕展示手环」再到「微笑推荐」，节奏完整、人物一致。

**但第一版通常有问题，我会用评测集量化并迭代**：

| 常见问题 | 定位 | 迭代手段 |
|----------|------|----------|
| 人物换脸/不一致 | 首帧未接力 | 强制首尾帧衔接 + 固定 seed |
| 手环屏幕文字乱码 | 模型不擅长渲染小字 | 提示词去掉具体文字，后期贴真实 UI |
| 手指变形 | 负向约束缺失 | 补「多手指/畸形手」负向词 |
| 运镜太快眩晕 | 运镜速度未限 | 明确 slow / static |
| 口播对不上嘴 | 生成阶段无音频 | 拆分「生成画面 + 后期对口型」两阶段 |

## 五、如何工程化落地（结合我简历里的项目串讲）

这一段是**从「会用工具」升级到「会建系统」**的关键，面试可重点讲：

1. **接入内容运营 Agent（项目五 · LangGraph 工作流）**
   - 用 SubGraph 把「选题 → 分镜脚本 → 首帧文生图 → 逐镜头 Seedance 生成 → 拼接」拆成独立编排节点；
   - PostgreSQL Checkpointer 持久化，某个分镜生成失败可**单节点重试**，不用重跑整条；
   - `asyncio.gather` 并发触发 3 个分镜生成 + 指数退避重试，整体耗时大幅下降。

2. **产物沉淀进多模态素材中心（项目七）**
   - 生成的养老产品视频不只是成片，还按 ASR 时间戳切成多条 `rag_assets`；
   - 核心理念：**不向量化视频本身，而向量化它的 `retrieval_text`（「这段视频能回答什么问题」）**，比如「防摔手环怎么报警」；
   - 于是 AI 客服被用户问到「老人摔倒怎么办」时，能直接**混排返回这段视频片段**（media_url 携带 `#t=秒数` 跳转精彩片段）。

3. **成本与可观测（项目五）**
   - `MetricsContext` 采集每次生成的耗时/失败率/成本；
   - 环境变量 Mock 开关解耦真实生成服务，本地可零成本联调；
   - LangSmith + request_id 全链路追踪，问题定位从小时级到分钟级。

4. **数据回流闭环（项目三 数据中台）**
   - 高转化的成片话术回流数据中台，成为微调语料 / 下一轮选题的素材，践行「AI 的一切都是数据」。

## 六、可能追问 & 应答（面试防守）

**Q：为什么不用纯文生视频，一步到位？**
A：带货主播要求人物强一致，文生视频每次长相会漂移。所以主路线是「文生图锁首帧 → 图生视频 → 首尾帧接力」，把一致性问题在首帧就解决掉。

**Q：口播怎么和画面对上？**
A：拆两阶段——Seedance 只负责画面和自然口型开合，音频用 TTS 声音复刻单独生成，再用对口型模型对齐；这样音画可独立迭代，改文案不用重生成画面。

**Q：养老产品有合规/信任风险，怎么控？**
A：和我做客服的思路一致——**提示词分层治理**：把「不得夸大医疗功效、不得承诺治病」设为**铁律级负向约束**，价格/功效话术走审核后的知识库，生成脚本先过合规校验节点再进生成。

**Q：怎么评估好不好，而不是凭感觉？**
A：建评测集，从「人物一致性、运镜稳定性、手部畸形率、提示词遵循度、口播自然度」多维打分（可用 VLM 自动初筛 + 人工复核），负样本重构、正样本回流，形成可对比的版本迭代。
